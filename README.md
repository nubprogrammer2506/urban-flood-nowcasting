# Urban Flood Nowcasting System

SIH MVP for high-resolution 0–3 hour urban flood nowcasting.

## Pilot Area

Rajendra Nagar, Pune, Maharashtra.

## Core Pipeline

Rainfall
→ Runoff
→ DEM Surface Flow
→ Drainage Network
→ Drainage Surcharge
→ Flood Depth
→ Road Risk
→ Flood-Safe Routing

## Current Milestone

M0 / M1 — Study-area definition and GIS data preparation.
